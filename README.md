# US Crime Data Analysis & Trend Modeling 📊

An end-to-end Exploratory Data Analysis (EDA) project analyzing multi-year US crime datasets to uncover seasonal patterns, regional trends, and statistical insights using Python.

---

### 🚀 Project Overview
This project was developed as part of my MSc in Data Science coursework at Kingston University, London. The goal was to transform raw, unstructured crime records into clean, queryable data frames and generate visual insights to understand longitudinal crime trends across regions.

---

### 🛠️ Tech Stack & Libraries
- **Language:** Python
- **Data Manipulation & Cleaning:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn
- **Environment:** Google Colab, Jupyter Notebooks

---

### 📈 Key Analytical Steps
1. **Data Cleaning & Preprocessing:** Handled missing values, standardized date-time formats, and filtered anomalies from multi-year records.
2. **Exploratory Data Analysis (EDA):** Aggregated data by year, season, and geographic region to isolate high-frequency crime categories.
3. **Trend Modeling & Visualization:** Plotted seasonal distribution curves and correlation heatmaps to visualize trends clearly.
